# 术语表

| 术语 | 项目里的意思 | 延伸阅读 |
| --- | --- | --- |
| 配置源 | 向插件提供「需要探哪些线路、用哪些版本文件名和阈值」的上游描述，不与本地推送会话混放，也不在源码里保存备份 | [配置源、分层与过期降级](modules/sources-and-degraded.md) |
| `Discovered` 与版本闸门（`client.version`） | 配置源适配器返回给探针层的归一化快照结构，包含启用线路、可选阈值以及不可回退的客户端版本下限 | [配置源、分层与过期降级](modules/sources-and-degraded.md) |
| `endpoint` 与 `mirrors` 模式 | 两种互斥的配置源方式：`EndpointSource` 从远程入口地址动态拉取线路表，而静态镜像列表模式直接读取本地填写的线路 | [配置源、分层与过期降级](modules/sources-and-degraded.md) |
| 降级诊断 | 主入口配置拉取失败后，借用备用出口或未超龄的旧快照去核对下游线路是否一起宕机；仅供附带线索，绝不用于判绿或告警 | [配置源、分层与过期降级](modules/sources-and-degraded.md) |
| 未判定（`unknown=True`） | 当缺少线上阈值、没有严格多数共识、分块超出安全内存上限或临时抓取不到证书时对结果打上的状态；既不计失败也不计为覆盖或恢复依据 | [十项探针判据、多数共识与分块轮转](modules/probes-and-rotation.md) |
| `NO_CACHE` 与缓存差异策略 | 入口配置、清单与版本文件携带禁缓存头及时捕捉滞后；块字节请求刻意不带破缓存头，以便真实检验边缘缓存是否损坏 | [十项探针判据、多数共识与分块轮转](modules/probes-and-rotation.md) |
| `Range` 分片校验 | 按字节区间拉取单个分块，要求返回 206 部分内容与匹配总大小；若服务器退回 200 整包则视为分片失效 | [十项探针判据、多数共识与分块轮转](modules/probes-and-rotation.md) |
| 严格多数 | 同一文件在所有有效回包镜像中出现次数超过半数的唯一指纹，用于确立线路一致性和分块对比基准，避免平票时随意指错 | [十项探针判据、多数共识与分块轮转](modules/probes-and-rotation.md) |
| 轮转覆盖率 | 按「线路 × 文件 × 分块」三元组顺序抽样并在 7 天窗口内实际校验通过的比例，区别于只看最后一次成功与否的瞬时绿灯 | [十项探针判据、多数共识与分块轮转](modules/probes-and-rotation.md) |
| `AlertState`（`FIRING` / `GREEN` 状态） | 围绕 M-of-N 连续失败窗口推进的告警状态机；仅在滑动窗口达到阈值后由 `GREEN` 转为 `FIRING`，并在连续恢复后回到 `GREEN` | [告警抑制窗口、持久化队列与人工确认](modules/alert-state-and-delivery.md) |
| 抑制键 | 绑定在下游探针结果上的上游问题标识；当上游入口或对应镜像清单正在报警时，屏蔽必然连带失败的下游噪音通知 | [告警抑制窗口、持久化队列与人工确认](modules/alert-state-and-delivery.md) |
| 待发队列 | 由状态机产生、在发送之前先行持久化到磁盘的消息队列；确保进程重启不丢告警并在向多群依次发送前允许复核作废 | [告警抑制窗口、持久化队列与人工确认](modules/alert-state-and-delivery.md) |
| submitted 状态 | QQ 官方平台主动发送调用未抛错后写入待发目标上的中间状态，只表示接口已接收提交并停止每轮重复自动推送，不代表管理员已查收 | [告警抑制窗口、持久化队列与人工确认](modules/alert-state-and-delivery.md) |
| 查看绑定与人工确认 | QQ 官方会话内由管理员先执行通知查看把当前查看者、会话和最早未确认条目临时绑定，再通过确认指令正式清除队列条目的两步机制 | [告警抑制窗口、持久化队列与人工确认](modules/alert-state-and-delivery.md) |
| 命令闸门 | 控制指令响应白名单、管理员权限、触发冷却及禁下整包策略的集中访问守卫，避免群内刷指令放大外部镜像带宽 | [目标校验、响应上限与命令闸门](modules/security-and-gates.md) |
| 出群净化 | 在渲染聊天消息前对外来线路名、文件名与错误详情清洗控制字符、全角改写平台标签并限制长度的步骤，防止伪造告警或误触发全体提及 | [目标校验、响应上限与命令闸门](modules/security-and-gates.md) |

证据状态：除特别标注外，本页基于当前源码已确认。
