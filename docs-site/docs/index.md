# 起步与安装部署

**AstrBot Resource Monitor**（插件标识 `astrbot_plugin_resource_watch`）是面向 **AstrBot** 聊天机器人的定时资源分发线路探测与告警插件。它不采集宿主机 CPU、内存或磁盘，而是按客户端一致的内容与协议判据巡检外部配置入口、资源清单、HTTP `Range` 分片、MD5 校验和、热更版本与整包以及 HTTPS 证书到期天数，并将去重后的故障和恢复状态推送到指定聊天会话。

## 为什么不只看 HTTP 200

资源分发链路最常见的线上故障往往在状态码层「全绿」：

- **上游配置拉不到时客户端静默回退**：用户端落回内置保底线路，表面无感，却一直拿不到新配置或新地址；
- **边缘缓存停留在半截或旧包**：镜像返回 `HTTP 200`，但字节长度或 MD5 与清单不一致，用户下完后校验拒收；
- **服务器忽略 `Range` 请求头**：请求分片返回 `200 OK` 整包，客户端分片续传退化成重头拉取，表现为下载极慢；
- **多镜像步调漂移或版本回退**：某条线路落后于多数线路，或者在线配置误改了客户端版本下限导致大面积无法更新。

因此，插件始终围绕**按内容散列认、从配置源现场发现、针对静默故障告警**三条准则工作，不在仓库源码中写死第二份线路表或阈值。

## 明确非目标与运行边界

为保持插件小巧可维护，以下边界属于刻意排除的范围：

- **不做可用率 SLA 统计与图表平台**：它是一个运维告警器，只保留近期告警状态与 7 天抽样分块覆盖游标，不保存长期历史报表。
- **不监控也不控制第三方上游主机**：不在本插件中介入宿主机指标或托管平台后台管理。
- **不自动修改线上配置或切换线路**：严格分离观测与写权限，避免误报触发错误切流。
- **不保存业务数据，仅存少量运行状态**：状态目录仅持久化故障窗口、7 天轮转游标与未送达队列；清空目录不会损坏业务，只会失去未确认通知并在重启后重新累计故障确认。

> **交互式接口参考**：需逐项核对 10 项探针触发规则、`64 MiB` 与 SSRF 安全防线、`8` 条 `/线路` 指令及 `Source` / `HttpClient` 扩展 SPI？可直接使用 [API 与组件参考](/api-reference/)。

## 安装与环境准备

- **运行环境**：Python `3.10+` 与可用的 AstrBot 宿主环境；运行依赖列于 `requirements.txt`（`aiohttp>=3.14.5`，通常已由 AstrBot 环境提供）。
- **加载方式**：将本仓库完整放入 AstrBot 的插件目录（如 `data/plugins/astrbot_plugin_resource_watch/`），确保 `main.py` 与 `watch/` 同级保留（插件以包内相对导入加载）；仓库内的 `.gitignore` 已将根目录 `/config.json` 与 `data/` 排除出版本控制。
- **最小离线自检**：在加载进 AstrBot 之前，可在插件根目录运行本地测试与地址防泄漏守卫：

```sh
python3 -m unittest discover -s tests -t . -v
python3 tools/check-no-endpoints.py --verbose
```

## 常用指令速览

默认仅在配置的通知会话（`notify.sessions`）与命令白名单（`command.allow_sessions`）内响应 `/线路` 指令（支持中英文子命令别名）：

| 指令 | 别名 | 用途与默认权限 |
| --- | --- | --- |
| `/线路 状态` | `/线路 status` | 汇总最近一轮全探针红绿状态、静音余期与 7 天分块覆盖率（白名单会话可读） |
| `/线路 测 <线路名>` | `/线路 test <线路名>` | 立即单测指定线路并在慢锁空闲时补查版本与证书，**绝不下载整包**（默认限管理员且受冷却控制） |
| `/线路 配置` | `/线路 config` | 拉取并展示当前生效的启用线路、客户端版本闸门与线上阈值摘要（默认限管理员且受冷却控制） |
| `/线路 静音 [时长]` | `/线路 mute [时长]` | 挂起告警投递并保留期间探测与恢复记录，如 `30m`、`2h` 或 `45`（分钟），缺省为 `30m`（默认限管理员） |
| `/线路 取消静音` | `/线路 unmute` | 立即结束静音并触发待发送队列投递（默认限管理员） |
| `/线路 覆盖率` | `/线路 coverage` | 查看近 7 天内「线路 × 文件 × 分块」轮转实际校验通过的比例 |
| `/线路 通知` | `/线路 notifications` | 查看当前会话最早一条待确认通知（专用于 QQ 官方等需人工确认渠道） |
| `/线路 确认` | `/线路 ack` | 核销本人刚通过 `/线路 通知` 查看到的通知条目（**始终限管理员**） |
