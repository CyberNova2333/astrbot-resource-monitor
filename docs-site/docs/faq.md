# 常见问题与排错

以下汇总了日常使用与开发集成过程中最常见的问题解答：

### Q: 如何添加第三方文档站或公共 API 域名的白名单？

**A**: 编辑 `tools/check-no-endpoints.py` 中的 `ALLOWED_HOSTS` 元组，添加不随私有部署变动的公共生态域名即可。

### Q: 告警触发后会如何通知我？

**A**: 插件支持向指定的 AstrBot 管理员私聊发送告警卡片，或直接向飞书/企业微信/Discord Webhook 发送报警消息。

## 故障排查通用步骤

1. **核对运行环境版本**：确保您的 Node.js / Python 或浏览器版本符合最低兼容要求；
2. **检查控制台报错日志**：绝大部分配置错误或权限拒绝在控制台中都有清晰的行号与原因提示；
3. **提交 Issue 反馈**：若确认遇到底层 Bug，欢迎前往 GitHub 仓库提交复现用例与诊断日志。
