# Quick Start

Monitor host server health and receive proactive alert cards directly through AstrBot.

## Core Problems Solved

- **Pain Point 1**: Lack of immediate visibility into bot server CPU / RAM exhaustion under heavy loads.
- **Pain Point 2**: Traditional server monitoring tools are too heavyweight or require separate dashboards.
- **Pain Point 3**: Alert noise caused by transient spikes lacking intelligent cooldown suppression.

---

## Prerequisites

Python 3.10+, AstrBot 3.4+, pnpm 12.6.0.

---

## Quick Installation & Launch

```bash
# 1. Install project dependencies
pnpm install

# 2. Run local tests and verification
pnpm test
```
